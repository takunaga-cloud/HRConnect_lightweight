第1章: AWS新規アカウント開設 & 初回セキュリティ設定

AWSの契約がこれからの方向けに、アカウント作成から安全な初期設定までの手順です。

1 AWS アカウントの新規作成（サインアップ）

用意するもの: メールアドレス、クレジットカード、SMS受信可能なスマートフォン

  1. AWS公式サイト にアクセスし、「今すぐ無料サインアップ」 をクリックします。
  2. メールアドレスと「AWSアカウント名（例: hrconnect-prod）」を入力し、認証コードを確認します。
  3. ルートユーザーの強力なパスワードを設定します。
  4. 連絡先情報（住所・電話番号）を入力します。アカウントの種類は個人/ビジネスどちらでも構いません。
  5. クレジットカード情報を登録します（※ 本人確認のため1USD前後の仮請求が行われますが、即時取り消されます）。
  6. 電話番号によるSMS認証（本人確認）を完了します。
  7. サポートプランの選択画面: 必ず 「ベーシックサポート - 無料」 を選択してください。（他の有料プランを選ぶと月額課金が発生します）。
2 ルートユーザーのMFA（多要素認証）有効化【必須セキュリティ】

ルートユーザーのアカウント乗っ取りによる高額請求被害を防ぐため、最初に必ず設定します。

  1. 作成したルートユーザー（メールアドレス）で AWS マネジメントコンソール にサインインします。
  2. 画面右上のアカウント名をクリックし、「セキュリティ認証情報」 を開きます。
  3. 「多要素認証 (MFA)」セクションで 「MFA デバイスの割り当て」 をクリックします。
  4. スマートフォンの認証アプリ（Google Authenticator や 1Password 等）で画面のQRコードをスキャンし、連続する2つのコードを入力して登録を完了します。
3 作業用 IAM ユーザーの作成 & アクセスキー発行

日々のデプロイやCLI操作でルートユーザーを使わないよう、専用の作業ユーザーを作成します。

  1. コンソール上部検索バーで 「IAM」 を検索して開きます。
  2. 左メニューの 「ユーザー」 → 「ユーザーの作成」 をクリックします。
  3. ユーザー名に deploy-admin と入力します（「AWS マネジメントコンソールへのユーザーアクセスを提供する」はチェックなしでOK）。
  4. 「許可のオプション」で 「ポリシーを直接アタッチする」 を選択し、検索窓に AdministratorAccess と入力してチェックを入れます。
  5. 確認して 「ユーザーの作成」 を完了します。
  6. 作成した deploy-admin ユーザーをクリックし、「セキュリティ認証情報」 タブを開きます。
  7. 「アクセスキー」セクションの 「アクセスキーを作成」 をクリックします。
  8. ユースケースで 「コマンドラインインターフェイス (CLI)」 を選択し、確認チェックを入れて進みます。
  9. 重要: 表示された 「アクセスキー ID」 と 「シークレットアクセスキー」（または .csv ファイル）を安全に保存します（二度と表示されません）。

第2章: 月額3ドルを絶対に超えない「コスト防壁（ガードレール）」の設定

予期せぬ課金を未然に防ぎ、月額3ドルを死守するための二重・三重のアラートを設定します。

4 AWS Budgets による多段階アラート設定（$1, $2, $3）

AWS標準の予算管理機能（AWS Budgets）を使い、月額上限3ドルに対する3段階の自動通知を設定します。

  1. コンソール上部検索バーで 「AWS Budgets」 を検索して開きます。
  2. 「予算を作成」 をクリックします。
  3. 予算タイプで 「コスト予算 - 推奨」 を選択します。
  4. 以下の通り予算詳細を設定します：
    • 予算名: HRConnect-Strict-Budget-3USD
    • 期間: 毎月
    • 開始月: 今月
    • 予算タイプ: 固定
    • 予算額: 3 USD
  5. アラートの設定（3段階）: [アラートを追加] をクリックし、以下を登録します：
    警戒レベル トリガー条件 しきい値 通知タイミング
    レベル1: 早期検知 実コスト 33.3% ($1.00) 累計で$1に達した時点でメール受信
    レベル2: 警告 実コスト 66.6% ($2.00) 累計で$2に達した時点でメール受信
    レベル3: 上限到達 予測コスト または 実コスト 100.0% ($3.00) 月内$3到達が見込まれた瞬間にメール受信
  6. 各アラートのメール受信先にご自身のメールアドレスを入力し、「予算を作成」 を完了します。
✔ 無料枠アラートの有効化:
「請求とコスト管理」→「環境設定」→「請求の環境設定」を開き、「無料利用枠の使用量のアラートを受信する」 にチェックを入れて保存してください。無料枠の85%に達した時点でAWSから自動通知されます。
💡 なぜ本構成は月額3ドル未満（ほぼ0円）に収まるのか？
  • 常時稼働サーバー（EC2）なし: 待機コスト月額数千円〜数万円が完全にゼロ。
  • NAT Gatewayなし: VPC NAT Gateway（月約$32の固定費）を一切使わないパブリックサーバーレス設計。
  • AWS新規アカウントの無料枠（12ヶ月無料 + 常時無料）:
    • AWS Lambda: 月100万回リクエスト ＆ 320万秒実行が永続無料。
    • Amazon DynamoDB: 25GBストレージ ＆ 25WCU/RCUが永続無料。
    • Amazon S3: 5GBストレージ（12ヶ月無料）。
    • Amazon Cognito: 50,000人アクティブユーザーまで永続無料。
    • API Gateway: HTTP APIは$1.00/100万回（12ヶ月間は月100万回無料）。
    • Amplify Hosting: 月15GBデータ転送・月50万回リクエスト無料。

第3章: ローカルPC環境の準備

5 AWS CLI の設定（初期化）

ローカルPCのターミナルで、ステップ3で取得したアクセスキーを設定します。

ターミナルで実行
aws configure
# AWS Access Key ID [None]: [ステップ3のアクセスキーIDを入力]
# AWS Secret Access Key [None]: [ステップ3のシークレットアクセスキーを入力]
# Default region name [None]: ap-northeast-1
# Default output format [None]: json

# 疎通確認（現在のアカウントIDが表示されれば成功）
aws sts get-caller-identity
6 必要ツールの確認（Docker, CDK）

デプロイに必要なツールが揃っているか確認します。

ターミナルで実行
# 1. Docker が起動しているか確認（Lambdaコンテナのビルドに必要）
docker ps

# 2. AWS CDK CLI がインストールされているか確認
npx cdk --version

第4章: サーバーレスインフラのデプロイ

7 CDKの初回ブートストラップ & デプロイ実行

初回ブートストラップ: 新規アカウントで初めてCDKを使うため、一度だけ実行します：

ターミナルで実行
npx cdk bootstrap aws://$(aws sts get-caller-identity --query Account --output text)/ap-northeast-1

インフラの一括デプロイ: プロジェクト直下の deploy.sh を実行します：

ターミナルで実行
chmod +x deploy.sh
./deploy.sh

第5章: フロントエンドの無料ホスティング（AWS Amplify）

9 Amplify Hosting へのデプロイ（待機時 $0）
  1. ソースコードをGitHubなどのリポジトリにプッシュします。
  2. AWSマネジメントコンソールで 「AWS Amplify」 を開き、「新しいアプリをホスト」 をクリックします。
  3. GitHubを選択して認証し、対象リポジトリと main ブランチを選択します。
  4. ビルド設定でルートの amplify.yml が自動認識されます。
  5. 「詳細設定」→「環境変数」 に、ステップ7でメモした値を入力します：
    変数名 設定値
    NEXT_PUBLIC_BACKEND_URL https://<ApiEndpointOutputの値>
    BACKEND_URL https://<ApiEndpointOutputの値>
    NEXT_PUBLIC_COGNITO_USER_POOL_ID <CognitoUserPoolIdOutputの値>
    NEXT_PUBLIC_COGNITO_CLIENT_ID <CognitoClientIdOutputの値>
  6. 「保存してデプロイ」 をクリックします。約3〜5分で公開URLが発行されます。

第6章: 緊急時のキルスイッチ（撤退・完全停止手順）

🚨 万が一のコスト超過や検証終了時の完全削除コマンド:
もし何らかの理由で即座にすべてのリソースを停止・削除し、一切の課金をストップさせたい場合は、以下のコマンドをターミナルで1回実行するだけで、CDKが作成したリソースがすべて完全に破棄されます。 
cd infra
npx cdk destroy --all --force
※ Amplifyアプリを削除する場合は、Amplifyコンソールの「アクション」→「アプリの削除」をクリックします。
